# 듣는 노트 — 앱의 의도와 사용 목적

작성일: 2026-09-19  
근거: 사용자와의 앱 개발 대화 및 현재 구현 상태  
문서 성격: 앞으로의 설계와 구현을 판단하는 목적 문서

이 문서는 사용자가 원하는 학습 경험을 정리한다. 목표 기능과 현재 기능은 구분한다. 기존 설계 문서와 학습 우선순위가 다르면, 이 문서에 정리한 최신 사용자 요구를 기준으로 삼는다.

## 1. 앱을 만드는 이유

사용자는 영어 문구를 읽고 이해해도, 실제 발화에서는 같은 문구를 알아듣지 못하는 경우가 있다. 단어 사이의 연결, 약해진 소리, 강세, 발화 속도 때문에 소리가 예상과 다르게 들린다.

기존 자막 도구에서는 자막 구간 전체를 듣는 것은 가능했다. 그러나 안 들리는 청크나 문장만 골라 반복하고, 자신이 들은 소리를 바탕으로 피드백받는 과정은 불편했다.

사용자가 원하는 핵심 경험은 다음과 같다.

> “안 들리는 부분을 계속 듣고 싶다. 내가 들은 소리를 한글로 적으면, 왜 그렇게 들릴 수 있는지 설명받고 싶다. 그 설명을 참고해서 다시 듣고, 처음과 어떻게 다르게 들리는지 확인하고 싶다.”

**이 앱의 목적은 실제 영어 소리와 사용자의 청각 인식 사이의 차이를 확인하고, 반복 청취와 피드백으로 그 차이를 줄이는 것이다.**

## 2. 학습의 중심

앱은 다음 세 가지 질문을 중심으로 구성한다.

1. 화자의 말이 내 귀에는 어떤 소리로 들리는가?
2. 어떤 발음 현상 때문에 그렇게 들릴 수 있는가?
3. 설명을 참고해 다시 들으면 무엇을 구별할 수 있는가?

문법, 번역, 표현, 어순 설명은 소리를 이해하는 데 필요한 만큼 제공한다. 의미 선택 문제나 문법 연습이 핵심 청취 과정을 대신해서는 안 된다.

혀·입술·성대의 움직임에 대한 설명도 청취를 돕는 용도로 사용한다. 사용자의 발음을 녹음해 점수를 매기는 기능은 현재 핵심 요구가 아니다.

한글 표기는 사용자가 들은 소리의 기록이다. 이를 영어의 정확한 발음 기호나 정답 발음으로 취급하지 않는다.

## 3. 사용자와 학습 자료

주 사용자는 영어 기술 설명을 듣는 한국어 사용자다. 반도체 테스트, 불량 분석, 제품 평가와 관련한 업무 영어가 주요 활용 상황이다. 일상 대화와 다른 주제의 영상에도 같은 학습 방식을 적용할 수 있어야 한다.

현재 자료는 The Slow Mo Guys 영상이다. 그러나 앱의 기능이 이 영상에만 의존해서는 안 된다. 사용자는 새로운 YouTube 링크를 넣어 같은 방식으로 학습할 수 있어야 한다.

사용자가 영상마다 문장을 직접 나누거나, 개발자에게 자막 정리를 요청하는 방식은 목표 사용 흐름이 아니다.

사용자가 자막 파일을 제공하지 않아도 라이브러리로 영상의 자막을 확보하고, AI가 학습용 청크·문장·문단으로 재구성해야 한다. 링크를 바꾼 뒤에도 같은 처리 과정이 작동해야 한다. 자막이 없는 영상의 음성 인식은 별도 과제로 남아 있으며, 자막 수집 실패를 생성 완료로 표시해서는 안 된다.

## 4. 한 번의 학습 흐름

1. 학습할 YouTube 영상을 선택한다.
2. 전체 문맥에 따라 정리된 자막에서 듣고 싶은 문장을 고른다.
3. 선택한 문장을 바로 듣는다.
4. 안 들리는 부분이 있으면 청크나 단어 범위로 좁힌다.
5. 필요한 만큼 반복하고, 처음 들린 소리를 한글로 적는다.
6. 필요하면 영어 자막과 AI의 발음 피드백을 확인한다.
7. 피드백에서 제시한 소리 단서에 집중해 다시 듣는다.
8. 다시 들린 소리와 여전히 어려운 부분을 기록한다.
9. 문장 전체를 다시 들어 앞뒤 문맥에서도 알아들을 수 있는지 확인한다.

처음 기록은 피드백 이후의 기록과 구분한다. 다시 들을 때마다 같은 답을 요구하거나, 반복 횟수를 강제로 제한하지 않는다.

## 5. 화면과 재생 방식

PC 화면에서는 왼쪽에 영상, 오른쪽에 자막을 배치한다. 사용자가 자막을 선택하면서 영상을 함께 볼 수 있어야 한다. 영상 아래에는 왼쪽에 반복·속도를, 오른쪽에 고정 폭의 선택 구간 듣기·멈추기 버튼을 둔다. 재생 상태가 바뀌어도 반복·속도의 위치가 움직이지 않게 한다. 반복·배속 옆에 현재 재생 모드(계속 이어 듣기·구간 한 번 듣기·구간 반복)를 고정 폭 버튼으로 표시한다. 이 버튼을 누르면 현재 위치부터 계속 이어 듣기와 현재 보기 구간 끝에서 멈추기를 전환한다. 정지 중에도 현재 위치부터 재생하며, 전환 시 반복을 해제한다. 원본 링크와 현재 위치도 표시한다. 구간 선택은 오른쪽 자막으로 모은다. 처음부터, 현재 위치를 시작·끝으로, 수동 시간 입력·복원 영역은 사용자 요청에 따라 제거한다. PC 학습 화면에서는 자막 패널을 화면 높이 안에 맞추고 목록만 스크롤하여 선택 단위·현재 위치 버튼을 영상과 함께 표시한다. 긴 설명은 사용 안내로 모아 처음에는 펼치고, 학습 시작 시 접으며 다음 방문에도 접힌 상태를 기억한다. 사용자가 안내를 다시 열 수 있다. 청취 기록과 발음 피드백은 오른쪽 ‘소리 노트’ 탭에 둔다. ‘자막 / 소리 노트’ 전환 중에도 왼쪽 영상과 입력 내용을 유지하고, 자막으로 돌아오면 이전 탐색 위치를 복원한다. 노트 상단에는 기록 대상 구절·시간과 구간 듣기 버튼을 둔다.

| 사용자 행동 | 기대 동작 |
|---|---|
| 문장 선택 | 해당 문장이 즉시 재생된다. |
| 청크 선택 | 해당 청크가 즉시 재생된다. |
| 문단 선택 | 의미상 연결된 문장들을 하나의 범위로 재생한다. |
| 시작 단어와 마지막 단어 선택 | 두 단어를 포함한 범위가 재생된다. |
| 반복 선택 | 선택 범위를 일정한 간격으로 반복한다. |
| 재생 진행 | 현재 들리는 문장·청크·단어의 위치를 표시한다. |
| 청취 범위 변경 | 오른쪽 자막에서 청크·문장·문단 또는 시작·마지막 단어를 선택한다. 수동 시간 입력은 제공하지 않는다. |
| 문장 전체로 복귀 | 좁힌 구간을 원래 문맥에서 다시 듣는다. |
| 영상 탐색 막대로 위치 이동 | 해당 위치의 자막으로 이동하고 이어 듣기로 전환한다. |
| 영상 자체의 재생 버튼 | 선택 구간 끝에 멈추지 않고 이어 듣는다. 자막을 누르면 다시 구간 연습으로 전환한다. |

선택한 구간의 표시와 현재 재생 위치의 표시는 구분한다. 위치 표시가 실제 발음과 맞지 않으면 학습자가 잘못된 소리와 단어를 연결할 수 있다.

## 6. AI가 담당해야 하는 일

### 6.1 새 영상의 문장과 청크 준비

목표 처리 흐름은 다음과 같다.

**새 링크 → 라이브러리로 자막 수집 → 전체 문맥 분석 → 문장·발화 및 청크·문단 구분 → 원문·시간 대응 검사 → 저장 → 학습 화면 제공**

AI는 자막 표시 줄이나 일정한 시간 간격을 문장 경계로 간주하지 않는다. 앞뒤 발화의 의미와 문법적 연결을 읽고 문장 경계를 판단한다.

문장이 여러 자막 줄에 걸쳐 있으면 연결한다. 한 자막 줄에 여러 문장이 있으면 나눈다. 마침표와 물음표도 문장의 의미에 따라 붙인다.

대화에는 짧은 응답, 감탄, 말 끊김이 있다. 이런 발화를 억지로 완전한 문장으로 고쳐 쓰지 않는다. 필요하면 독립된 발화 단위로 구분한다.

청크는 문장 안에서 함께 들을 만한 의미·발화 단위다. 단어를 일정 개수씩 자른 결과를 의미 있는 청크라고 표시해서는 안 된다.

처리는 영상 전체에 적용한다. 도입부만 정리하고 뒤쪽을 시간 기준 분할로 대체해서는 안 된다. 일부만 처리했다면 완료 범위를 표시한다.

### 6.2 발음과 청각 인식에 대한 피드백

AI는 선택한 영어 구절, 주변 문맥, 사용자의 한글 기록을 함께 참조한다. 다음 항목 중 해당 구간에 필요한 내용을 설명한다.

- 단어 경계가 다르게 들릴 가능성
- 연결, 약화, 탈락, 강세 때문에 예상과 달라지는 소리
- 소리를 이해하는 데 도움이 되는 혀·입술·성대의 움직임
- 다음 재청취에서 확인할 구체적인 소리 단서
- 피드백 전후의 한글 기록에서 달라진 부분

설명은 한 번에 확인할 수 있는 소수의 단서로 좁힌다. 사용자의 한글 기록만으로 듣기 능력이나 발음의 정확도를 확정하지 않는다.

### 6.3 AI 설명의 근거 표시

자막과 한글 기록만 사용했다면 **텍스트에 근거한 발음 가설**로 표시한다. 실제 음성을 분석하지 않았는데 화자의 발음을 확인했다고 말하지 않는다.

AI의 문장 분석과 음성의 시간 정렬은 별도 작업이다. 문장을 올바르게 나눠도, 그 문장의 실제 시작·끝 시간이 정확해지는 것은 아니다.

단어 시간을 추정했다면 추정값임을 표시한다. 정확한 단어 재생을 위해서는 원음과 텍스트의 시간 대응을 별도로 확보해야 한다.

## 7. 자막과 기록을 다루는 원칙

한 영상의 서로 다른 자막 출처를 섞어 중복 표시하지 않는다. 반면 화자가 실제로 반복한 말은 임의로 제거하지 않는다.

문장 구분 과정에서 원문 단어가 빠지거나 추가되거나 순서가 바뀌었는지 검사한다. 자막 오류 수정은 문장 구분과 별도로 다룬다. 원문과 수정 내용을 구분할 수 있어야 한다.

학습 기록에는 영상, 선택 구절, 시간 범위, 처음 들은 소리, 피드백, 다시 들은 소리를 연결한다. 영상이나 자막 분석 결과가 바뀌어도 기존 기록을 잃지 않아야 한다.

학습 결과는 “이 소리를 구별하게 됐다”, “이 부분은 아직 어렵다”처럼 실제 기록으로 설명한다. 근거 없는 영어 등급이나 향상 점수를 만들지 않는다.

## 8. 현재 구현과 목표의 차이

아래 상태는 이 문서 작성 시점의 구현을 기준으로 한다.

| 항목 | 현재 상태 | 목표 상태 |
|---|---|---|
| 새 YouTube 링크 추가 | 라이브러리 자막 수집 후 AI 분석을 요청한다. 수집한 원본과 분석 결과를 저장한다. | 여러 실제 영상에서 의미 구분과 재생 싱크까지 검증한다. |
| 현재 영상의 문장 구분 | 대화에서 AI가 정리한 339개 문장·발화 결과를 저장해 사용한다. | 영상별 분석 결과를 앱이 준비하고 관리한다. |
| 새 영상의 AI 문장 분석 | Gemini 실서비스로 두 영상의 전체 자막 분석과 범위 검증을 완료했다. 현재 영상은 3,218단어, 456개 문장·발화, 955개 청크, 20개 문단으로 준비했다. 의미 구분 품질과 실제 청취 싱크는 별도 검증이 필요하다. | 전체 자막의 의미 구분 품질을 여러 영상에서 확인한다. |
| 청크·문단 구분 | 새 AI 분석 결과의 청크·문단 선택을 구현했다. 기존 분석 없는 자료의 임시 청크는 규칙 기반임을 표시한다. | 의미와 발화 흐름에 맞는 구분을 실제 재생으로 확인한다. |
| 구간 선택과 반복 | 문장·청크·단어 범위 선택 및 반복 조작, 보기 전환 시 위치 유지, 문장 안 청크·문단 안 문장 선택을 구현했다. 구간 선택을 오른쪽 자막으로 모으고 중복 재생·수동 시간 조정 UI를 제거했다. 영상 탐색에 따른 자막 이동과 이어 듣기를 구간 연습에서 분리했다. 학습 중 선택 버튼을 유지하고 사용 안내를 접도록 화면을 정리했다. 자막 목록의 방향키·Enter·Shift+Enter 조작과 오른쪽 고정 폭 재생 버튼을 구현했다. 미세 탐색 판별과 모든 브라우저에서의 검증은 남아 있다. | 실제 음성 경계와 맞는 재생을 제공한다. |
| 현재 재생 위치 | 추정한 단어 시간으로 표시한다. 현재 위치의 파란 테두리·재생 중 밑줄과 상위 보기에서 이전 구간을 찾는 노란색을 구분한다. | 원음과의 시간 대응 정확도를 확보한다. |
| 발음 피드백 | 질문을 복사해 ChatGPT 대화에서 받을 수 있다. 로컬 AI 설정 시 앱 안에서도 요청할 수 있다. | 청취 기록과 연결된 피드백을 앱 안에서 이어간다. |
| 기록 보관 | 로컬 저장과 백업을 제공한다. 소리 노트를 연습실 오른쪽 탭에서 작성한다. 학습 기록을 소리 노트·의미 이해 연습 기록·최근 연습 노트 탭으로 구분한다. 날짜가 있는 노트는 월·월요일 시작 주·일로 묶으며 이번 달·이번 주·오늘만 기본으로 펼친다. 각 기간과 전체 목록을 접거나 펼칠 수 있고, 탭 왕복 시 접힘 상태를 유지한다. 영어 구절·한글 기록 검색과 영상 필터를 사용할 수 있으며 검색 결과는 지난 기간도 펼쳐 보여준다. 의미 이해 요약은 전체 기간 누적이고, 날짜별 응답은 최근 연습 노트에서 전체 저장 기록을 조회한다. 기록에서 저장한 구간과 노트를 다시 연다. 연결되지 않는 자막의 기록도 목록에 보존한다. 같은 항목은 최신 기록으로 갱신하며 날짜별 이력 누적은 아직 제공하지 않는다. | 분석 결과가 변경돼도 기록의 연결을 유지한다. |

**실제 Gemini 응답으로 전체 자막 준비와 구조 검증은 완료했다. 의미 구분 품질과 원음 싱크 검증은 남아 있다. 단어 시간은 자막 구간 안에서 추정한다. 음성 정렬 및 자막 없는 영상의 자동 전사는 아직 구현하지 않았다.**

현재 영상의 전용 분석 결과와, 모든 새 영상에 적용되는 자동 처리 기능을 구분해서 설명해야 한다.

## 9. 개발 우선순위와 완료 기준

우선순위는 문장 구분, 재생 시간의 정확성, 청크 구분, 발음 피드백 연결 순서다. 문장 구분이 불안정한 상태에서 다른 학습 기능을 늘리지 않는다.

다음 조건으로 목적 달성 여부를 확인한다.

1. 새로운 영상에서도 개발자의 개별 수정 없이 문장을 준비한다.
2. 영상 처음부터 끝까지 의미에 따른 문장·발화 구분을 제공한다.
3. 서로 다른 자막 출처 때문에 같은 내용이 중복되지 않는다.
4. 문장이나 청크를 누르면 의도한 소리 범위가 재생된다.
5. 현재 위치 표시가 재생 중인 발화와 대응한다.
6. 처음 들은 소리와 피드백 후 들은 소리를 비교할 수 있다.
7. AI의 분석 근거와 미확인 부분을 확인할 수 있다.
8. 새 영상을 추가해도 이전 학습 기록이 유지된다.

## 10. 아직 결정하거나 구현해야 할 사항

- 실제 AI 분석의 의미 구분 품질과 여러 영상의 재생 싱크 검증
- AI 사용에 필요한 설정, 처리 시간, 비용의 안내 방식
- 자막이 없거나 수집에 실패한 영상의 처리 방식
- 원음과 문장·단어 시간을 맞추는 방법
- 분석 오류를 사용자가 고치고 다시 사용하는 방법
- 하나의 문장에 여러 청취 시도를 누적하는 기록 방식

이 항목들은 구현이 완료된 기능이나 확정된 기술 선택을 뜻하지 않는다.

## 연속성 있는 학습 화면 (2026-09-20)

청크·문장·문단의 보기 단위를 전환해도 재생 위치와 기존 반복 범위를 유지한다. 재생 중에는 현재 소리가 속한 단위로 목록을 이동하고, 멈춘 뒤에는 마지막 학습 위치를 이어서 표시한다. 청크에서 문장으로 전환하면 이전 청크 전체를, 문장에서 문단으로 전환하면 이전 문장 전체를 노란색으로 이어서 강조한다. 문단에서 문장·청크로 내려가면 현재 발음 위치에 해당하는 항목으로 이동하고 파란 테두리로 표시한다. 노란색은 실제로 듣던 구간이 있는 청크 → 문장, 문장 → 문단 전환에만 사용한다. 새 구간을 선택하면 지우며, 문단 전체 선택이나 학습 위치가 없는 상태에서는 표시하지 않는다. 재생 중인 청크·문장은 파란 밑줄로 구분한다. 단어마다 별도의 강조 상자를 만들지 않는다. 문장 안에서는 청크를, 문단 안에서는 문장을 눌러 해당 부분을 재생할 수 있다. 시간 옆 재생 버튼은 해당 문장·문단 전체를 재생한다. 자막을 직접 선택하면 해당 단위로 반복 범위를 바꾼다. 현재 위치로 돌아가기 버튼은 검색을 해제하고 학습 위치를 다시 보여준다. 긴 문단에서는 내부의 현재 문장을 스크롤 기준으로 삼는다. 클릭한 문장이 이미 보이면 위치를 유지하고, 화면 밖으로 벗어날 때만 목록을 이동한다.

추가 UI 제안은 문단 > 문장 > 청크 위치 경로, 현재 문장 중심으로 앞뒤 문맥을 펼치는 보기, 학습 구간을 표시하는 시간 막대다. 아직 이 추가 보기들은 구현하지 않았다. 음성과 자막의 싱크는 저장한 기준 자료를 변경하지 않고 보존한다.

영상 위치를 기준으로 자막을 따라갈 때는 재생 명령을 보내지 않는다. 자막을 명시적으로 선택할 때만 구간을 변경하고 이동·재생한다. 영상 탐색 시 이전 구간의 반복 예약을 취소한다. 자막을 직접 스크롤하면 자동 스크롤을 멈추며, ‘현재 위치로 돌아가기’, 영상 탐색, 자막 선택 시 다시 따른다. 영상 탐색만으로 학습 노트의 대상 구간이나 기존 기록을 바꾸지 않는다.

YouTube 상태 이벤트만으로 조작 주체를 완전히 구분할 수 없으므로 앱이 요청한 탐색·반복과 영상 시간의 불연속을 함께 확인한다. 작은 탐색은 감지되지 않을 수 있고, 버퍼링·브라우저별 이벤트 순서에 대한 추가 검증이 필요하다. 원본 자막과 시간 정보는 수정하지 않는다.


## 키보드로 구간 탐색과 듣기

자막 목록에 포커스가 있을 때만 단축키를 적용한다. ↑↓는 현재 보기의 이전·다음 항목으로 탐색 위치만 옮긴다. ←→는 단어·청크·문장·문단 순서로 보기를 전환하며 탐색하던 시간 위치를 유지한다. 키보드 탐색은 점선으로 표시하고 영상 재생 위치와 구분한다. 목록 탐색 중 자동 스크롤은 멈춘다.

Enter는 선택한 항목을 한 번 재생한다. 단어 보기에서는 Enter 두 번으로 시작·마지막 단어를 지정한다. Shift+Enter는 선택 항목의 시작부터 연속 재생한다. 연속 재생 중 Enter는 현재 들리는 항목의 끝까지 듣고 멈추며 처음으로 되돌아가지 않는다. 키보드로 요청한 한 번 듣기·연속 재생·항목 끝 정지는 반복을 해제한다. 검색창·학습 기록 입력창·영상 자체의 키보드 조작에는 개입하지 않는다.


## 학습 화면 유지와 변경 검증

학습 중에는 소개·영상 선택·AI 준비 영역을 접고 ‘영상 설정’으로 다시 연다. 일반 PC 화면에서 영상과 오른쪽 패널이 화면 높이 안에 머물며 자막·노트 안에서 스크롤한다. 매우 작거나 낮은 화면은 세로 스크롤을 허용한다. 자막 탭 또는 보기 단위를 선택하면 자막 목록에 포커스를 돌려 방향키·Enter 조작을 이어간다. 입력창과 영상 자체의 키 처리는 유지한다. 화면 변경마다 앱 작업 규칙에 연결된 UI 회귀 검증을 수행한다.


## 모바일 중심 청취 화면 (2026-09-20)

화면 폭 850px 이하의 주 입력 장치가 터치인 기기에서는 기본 화면을 영상·자막 중심으로 구성한다. 설정 버튼으로 영상 선택, 재생 속도·반복 조작, 검색, 보기 선택, 소리 노트 탭과 메뉴를 다시 표시한다. 설정을 접어도 노트 입력과 영상은 유지한다. 영상과 자막 영역을 세로로 배치하고 자막 목록을 스크롤한다.

- 자막 틀의 여백이나 시간 표시: 해당 자막 시작부터 연속 재생. 같은 틀을 다시 누르면 즉시 정지.
- 내부 청크·문장: 해당 구간 반복. 같은 구절을 다시 누르면 즉시 정지하며 대기 중 반복 예약도 취소.
- 단어 범위: 시작·마지막 단어를 선택해 포함 범위를 반복. 선택 범위의 단어를 다시 누르면 정지. 한 단어만 들으려면 같은 단어를 시작·끝으로 선택.
- 왼쪽 스와이프: 청크 → 문장 → 문단 → 단어 범위. 오른쪽은 역순. 양 끝에서는 유지. 보기만 바꾸며 재생 위치·반복 범위는 유지.
- 세로 스크롤과 짧은 터치는 보기 전환으로 처리하지 않고, 스와이프 직후 클릭으로 재생하지 않는다.

PC의 클릭·방향키·Enter·Shift+Enter 및 입력창 조작은 기존 방식을 유지한다. 좁은 PC 창만으로 터치 조작을 활성화하지 않는다. 2026-09-20 사용자가 갤럭시 S22에서 설정 표시, 틀의 연속 재생·정지, 내부 구절 반복·정지, 단어 범위 반복·정지, 좌우 스와이프를 정상 동작으로 확인했다. 자막과 추정 시간, 저장한 싱크 기준 자료는 변경하지 않는다.

모바일 영상은 자막 패널과 같은 폭의 16:9 영역에 표시한다. 보기 이름 옆에 멈춤·반복 듣기·계속 이어 듣기를 직접 선택하는 버튼을 둔다. 멈춤은 반복 대기도 취소한다. 반복 듣기는 기존 선택 구간의 처음부터 반복하고, 계속 이어 듣기는 반복을 해제하며 현재 영상 위치부터 재생한다. 보기 전환이나 상태 버튼만으로 기록 대상과 자막 시간을 바꾸지 않는다. 현재 상태는 실제 플레이어 상태로 표시하며, 한 번 듣기는 별도 안내한다. 2026-09-20 사용자가 영상 폭과 세 상태 버튼의 동작을 정상으로 확인했다. 버튼의 세로 크기가 부담스럽다는 의견에 따라 최소 높이를 44px에서 32px로 줄이고 상태 영역의 위아래 여백을 줄인다. 축소 후 터치 편의는 추가 사용 확인이 필요하다.
