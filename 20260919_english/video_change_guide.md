# 영상 변경과 학습 이어가기 — 링크만 입력

개정일: 2026-09-19 / 설계 단계, 구현 전

## 사용자가 할 일

**YouTube 링크를 붙여넣고 ‘연습 준비’를 누릅니다.**

자막 파일, 학습 구간, 어려운 점, 이미 학습한 구간을 미리 입력할 필요가 없습니다. 앱이 기존 학습 기록을 참고해 준비합니다. 이 문서는 이전의 자막 필수·수동 학습팩 제출 안내를 대체합니다.

## 앱이 준비할 것

1. 영상과 사용 가능한 영어 자막을 확인합니다.
2. 시간 정보와 문맥을 정리하고 학습할 구간을 선정합니다.
3. 긍정·부정, 숫자, 조건, 자주 놓친 문장 구조를 중심으로 연습을 만듭니다.
4. 자막·정답의 불확실성을 검사하고 준비된 구간부터 시작합니다.
5. 기존 복습과 새 영상 연습을 연결합니다.

라이브러리는 기존 자막을 가져오는 도구이므로 모든 영상에서 정확한 자막을 얻는다는 보장은 없습니다. 자막이 없거나 접근되지 않는 영상은 준비 보류 상태로 알리고, 준비 가능한 추천 영상이나 기존 연습으로 이어갑니다. 자막 첨부는 원하는 사용자에게만 고급 옵션으로 둡니다.

## 앱이 학습 중 알아갈 것

- 첫 응답, 다시 듣기, 자막·뜻 보기, 속도 변경을 통해 필요한 도움을 추정합니다.
- 구간·표현별 학습 이력과 복습 시기를 누적합니다.
- 가끔 ‘소리가 안 잡힘 / 뜻이 낯섦’ 같은 짧은 선택만 묻고 건너뛰기를 허용합니다.
- 앱 밖에서 본 영상은 자동으로 알 수 없으므로 미확인으로 두며, ‘이미 익숙해요’로 간단히 알려줄 수 있습니다.
- 중단·반복·건너뛰기만으로 능력이 낮다고 판단하지 않습니다.

학습자는 구간 분석이나 자막 정리 대신 듣고 의미를 이해하는 데 집중합니다. 자동 선정이 맞지 않으면 ‘더 쉽게’, ‘다른 구간’, ‘답이 이상해요’로 조정합니다.

## 영상 변경 후에도 남는 것

학습 목표, 최초 수준 기록, 날짜별 답변, 도움 사용, 익힌 표현, 복습 일정은 영상과 독립적으로 보존합니다. 새 영상에 필요한 표현이 없으면 기존 영상이나 보조 음성에서 이어갑니다. 진행 중인 세션은 계속하거나 끝낼 수 있고, 새 영상은 다음 세션부터 주 자료로 사용합니다.

같은 영상 재등록·자막 수정도 이전 노출과 연결합니다. 영상이 삭제되거나 재생되지 않으면 기록은 남기고 같은 목표의 다른 자료를 제안합니다.

## 새 자료 추천

앱을 사용할 때 주간 갱신 시점이 지났으면 관련 영상·사이트를 확인하여 소수의 후보와 추천 이유를 제시하도록 설계합니다. 사용자는 ‘이걸로 연습’을 누르면 됩니다. 앱이 꺼진 동안에도 실행하려면 별도 예약 실행 환경이 필요합니다. 현재 정기 조사 작업이 실제로 설정된 상태는 아닙니다.

## 저장과 운영

v2는 로컬 서비스의 데이터베이스에 학습 기록과 콘텐츠를 저장하고 브라우저는 임시 상태를 보관하는 구성을 제안합니다. 기기를 바꿀 때는 기록·복습·콘텐츠 백업을 가져옵니다. 클라우드 동기화는 아직 기본 범위가 아닙니다.

AI 공급자와 실행 환경 설정은 최초 설치에서 처리합니다. 일반 학습에는 링크 외 입력을 요구하지 않지만, 자동 준비에 필요한 서비스 설정·비용이 없는 것은 아닙니다. 자동 준비가 일시적으로 안 되어도 이미 준비된 콘텐츠는 계속 사용할 수 있게 합니다.

상세 동작·품질 기준·출처는 [학습 자동화 설계 v2](adaptive_learning_design.md)를 따릅니다.
