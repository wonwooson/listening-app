# 소리 중심 듣기 — 2026-09-19 변경 사항

최신 사용자 요청에 따라 앱의 첫 화면과 우선 학습 목표를 변경한다. 기존 문서의 의미 선택·문법·어순 연습은 보조 활동으로 남긴다.

주요 흐름은 원본 영상 구간 선택 → 문장 또는 청크에 맞게 시간 조정 → 반복 청취 → 들린 소리를 한글로 기록 → 발음 가설 피드백 → 재청취 → 달라진 청각 인상 기록이다. 한글 표기를 정답 발음이나 발음 점수로 사용하지 않는다.

## 구현된 범위

- 첫 화면 ‘소리 연습실’에서 준비된 영상 자막 구간을 검색하고 선택한다.
- 시작·끝을 0.1초 단위로 수정하거나 현재 영상 위치로 지정한다. 원래 구간 앞뒤 30초 안에서 문장 전체나 청크를 직접 지정할 수 있다.
- 선택 구간 반복, 0.7초 간격, 영상이 지원하는 재생 속도를 제공한다. YouTube 탐색에는 오차가 있을 수 있다.
- 처음 들은 소리, 집중 구절, 피드백, 다시 들은 소리를 구간별로 저장한다. 같은 자막 구간의 노트는 최신 기록으로 갱신한다. 여러 청크를 별개 노트로 보관하는 기능은 아직 없다.
- ‘ChatGPT 질문 복사’로 영상·시간·주변 자막·내 기록을 대화에 전달한다. 받은 답은 피드백 칸에 붙여넣고 다시 듣는다. 자동 계정 연동은 없다.
- 기존 로컬 Ollama 모델 설정이 있으면 앱 안에서 텍스트 기반 발음 가설도 받을 수 있다. 설정이 없어도 질문 복사와 기록은 사용 가능하다.
- 기록은 기존 SQLite 백업에 포함한다. 저장 전 입력은 브라우저 임시 보관으로 복구하며, 다른 컴퓨터로 옮길 때는 저장 후 백업해야 한다.

## 정확성 경계

자동 문장·청크 분할이나 원음 분석을 구현한 것은 아니다. 수집 자막은 실제 말과 다를 수 있고, 선택 범위에 맞는 구절도 사용자가 확인한다. 피드백은 연결·약화·강세·단어 경계에 관한 가능한 설명과 재청취 단서를 제공한다. 실제 화자의 발음을 들었다고 주장하거나 사용자의 발음을 채점하지 않는다.

## 화면 원칙

기존 흰색(#ffffff), 옅은 청회색(#f3f5f9), 남색 글자(#202c43), 파랑 조작색(#234ae3), 회색 보조 설명(#627089)을 유지한다. Noto Sans KR/Malgun Gothic으로 한국어 기록을 읽기 쉽게 표시하고, 영어 자막은 Segoe UI를 사용한다. 왼쪽은 영상·구간·자막 목록, 오른쪽은 청취 노트다. 좁은 화면에서는 영상 다음에 노트가 이어진다. 장식 대신 시간 범위와 처음/다시 들은 소리를 중심으로 구성한다.
