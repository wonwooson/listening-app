# 듣는 노트

영어 기술 설명을 듣기 위한 개인용 리스닝 앱 첫 버전입니다.

## 실행

Windows에서 `Start-App.cmd`를 실행하거나 PowerShell에서 `./Start-App.ps1`을 실행합니다. 주소는 **http://127.0.0.1:8765**입니다. 종료는 실행 중인 uvicorn 프로세스를 종료하면 됩니다. 학습 기록은 `data/listening.sqlite3`에 남습니다.

개발 실행:

```powershell
python -m uvicorn backend.server:app --host 127.0.0.1 --port 8765
```

다른 창에서 `npm run dev`를 실행하면 화면 개발 서버는 5173 포트에서 열립니다. `npm run build`는 배포 파일을 만듭니다. Python 3.11 이상과 Node 20.19 이상을 권장합니다.

## 지금 사용할 수 있는 기능

- YouTube 링크 등록, 시간 자막 자동 수집, 문맥을 묶은 자유 청취 구간 준비.
- 긍정·부정, 확실성, 문장 구조, 숫자를 다루는 별도 작성 연습 15문장. 설치된 Windows 영어 음성으로 로컬 WAV 생성.
- 구간 반복, 속도 조절, 영어 자막, 의미 피드백과 다음 문장.
- 최초 응답·반복·도움 사용 저장, 다음날/3일 뒤 복습, 최근 어려움에 따른 목표 추천.
- 영상 변경 후 학습 기록 유지, 중단 세션 이어하기, JSON 백업 및 병합 복원.
- 2026-09-19 대화 기반 최초 수준 기록.
- Tektronix·Keysight 공식 학습 사이트 추천. 앱 사용 시 마지막 확인으로부터 7일이 지나면 접근 가능 여부와 포함된 영상 링크를 다시 확인합니다. 앱이 꺼진 동안 실행되는 예약 작업이나 폭넓은 웹 검색은 아닙니다.

## AI 설명 연결

로컬 Ollama에서 사용할 모델이 설치·실행되어 있다면 서버 실행 전에 `LISTENING_AI_MODEL` 환경 변수에 모델명을 지정합니다. 서비스는 127.0.0.1:11434의 Ollama에 요청합니다. API 키나 외부 계정 없이 사용할 수 있지만 모델 설치는 별도입니다. 설치되지 않은 모델을 자동 다운로드하지 않습니다.

연결하지 않아도 기본 문장 연습과 영상 자유 청취는 작동합니다. 영상의 한국어 설명은 AI가 연결된 경우에만 생성하며 AI 설명임을 표시합니다. 음성 검증이나 정답 확정으로 간주하지 않습니다.

## 현재 한계

임의 영상의 AI 생성 문항을 자동으로 확정 채점하지 않습니다. 자막 기반 영상 구간은 자기 점검이며, 검수된 별도 작성 문장만 채점합니다. 자막 없는 영상·수집 차단은 준비 불가로 표시하고 기존 연습을 유지합니다. AI 자동 문항 확장과 다화자 음성, 폭넓은 정기 웹 탐색은 후속 단계입니다. 합성 음성의 성과를 실제 화자 청취 성과로 해석하지 마세요.

기록은 이 컴퓨터에만 저장합니다. 백업 파일에는 개인 응답이 포함될 수 있으므로 공유 전 내용을 확인하세요. 외부 영상은 YouTube에서 재생되며 백업에 영상 파일을 넣지 않습니다.

## 검증

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
npm run build
```

실제 자동 수집·재생은 네트워크와 영상 접근 조건에 따라 달라집니다. 원본 링크와 수집 라이브러리는 자막 정확도를 보장하지 않습니다.

2026-09-19 확인: 자동 테스트 11개 및 프로덕션 빌드 통과. 제공된 YouTube 영상의 시간 자막 자동 수집으로 67개 구간을 준비했고, 실행 중인 서버의 홈페이지와 연습 WAV 응답을 확인했습니다. 연결 가능한 자동화 브라우저가 없어 화면 표시와 버튼 조작, YouTube 내장 재생의 실제 동작은 직접 검증하지 못했습니다. AI 모델도 아직 연결하지 않아 AI 설명 생성은 실환경 검증 전입니다.

현재 연습 풀은 15문장으로 제한되어 있습니다. 반복 문장의 정답률 상승만으로 새로운 발화 이해 능력이 향상되었다고 판단하지 않습니다. 한 달 비교를 위해서는 학습에 노출되지 않은 문장과 실제 화자 자료를 추가하고, 합성 음성 연습과 영상 자기 점검 결과를 구분해 평가해야 합니다.
# 소리 연습실

`Start-App.cmd`를 실행하면 소리 중심 연습 화면이 열립니다. 영상의 자막 구간을 고른 뒤 시작·끝 시간을 문장이나 청크에 맞게 조절하고 반복해 들으세요.

1. 처음 들린 소리를 한글로 적습니다.
2. 필요하면 자막을 펼치고 집중할 영어 구절을 적습니다.
3. **ChatGPT 질문 복사**를 눌러 대화에 붙여넣습니다. 답변은 앱의 피드백 칸에 붙여넣습니다.
4. 다시 듣고 달라진 소리를 기록한 뒤 **구간과 기록 저장**을 누릅니다.

로컬 AI 설정이 있다면 앱 안에서도 발음 가설을 받을 수 있습니다. 원음을 분석한 결과는 아니며, 자막과 한글 기록을 바탕으로 추론합니다. 문장·청크 경계는 직접 맞추며 YouTube 탐색 오차가 있을 수 있습니다. 기존 의미 연습은 왼쪽 **의미 이해 연습**에 남아 있습니다.

구간별로 최신 노트 하나를 보관하며 저장된 노트는 설정의 백업에 포함됩니다. 메뉴 이동 전 저장을 권장하며, 저장하지 않은 입력도 같은 브라우저에서 해당 구간을 다시 선택하면 임시 복구됩니다.
