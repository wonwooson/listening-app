# 리스닝 앱 작업 규칙

이 폴더에서 작업을 시작할 때도 [상위 프로젝트 규칙](../AGENTS.md)을 읽고 따른다.

매 코드 수정 작업 전에 [앱의 의도와 사용 목적](../20260919_english/app_purpose_and_intent.md) 전체를 파일에서 직접 읽는다. 이전 작업에서 읽었다는 이유로 생략하지 않는다.

수정 전에는 관련 목적과 기대 동작을 설명한다. 수정 후에는 목적과의 부합 여부, 검증 결과, 남은 한계를 보고한다. 상세 기준은 상위 프로젝트 규칙을 따른다.


## 화면 변경 후 필수 회귀 검증

탭·패널·포커스·레이아웃을 변경하면 [화면 조작 회귀 검증](tests/ui-regression.md)을 실제 브라우저에서 수행한다. 빌드와 단위 테스트만으로 기존 UI 조작 검증을 대신하지 않는다. 자막 탭 클릭 직후와 소리 노트에서 돌아온 직후의 네 방향키, Enter, Shift+Enter를 포함한다. 검증한 항목과 미검증 항목을 기록한다. 사용자 기록에 검증용 값을 저장하지 않는다.
